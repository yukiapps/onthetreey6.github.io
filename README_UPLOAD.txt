yukiapps GitHub Pages v11（審査提出前・先行公開版）

今回の変更
- リンク先がまだ存在しない「App Storeで見る」ボタンを全ページから削除
- トップページは「詳しく見る」を主ボタンへ変更
- 各アプリ詳細ページは「お問い合わせ」を主ボタンへ変更
- 「対応OSの詳細はApp Storeをご確認ください」という公開前には不自然な文言を削除
- CSSファイル名をv11へ変更し、旧キャッシュを回避

公開手順
1. このZIPを展開
2. 中のファイルをすべて選択
3. GitHubリポジトリの最上位へ上書きアップロード
4. ZIPそのものはアップロードしない
5. GitHub Pagesの公開完了後、Safariで再読み込み
6. 各詳細ページ・サポートページ・プライバシーポリシーのリンクを確認
7. App Store ConnectへURLを登録し、アプリを審査へ提出

App Store公開後
- 正式なApp Store URLをサイトへ追加
- トップページと各アプリ詳細ページに「App Storeで見る」ボタンを戻す
